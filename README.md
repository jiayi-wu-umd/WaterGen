> **TL;DR** — WaterGen generates diverse underwater images while independently controlling
> scene content and physical water-medium effects. A LoRA-adapted diffusion backbone
> first synthesizes a clean underwater scene latent; a medium-conditioned decoder then
> applies attenuation, scattering, and background light. The same scene can be rendered
> under many water conditions without changing geometry, producing paired clean/degraded
> images for downstream restoration and segmentation.

## Overview

WaterGen treats underwater generation as two separate controls: **what is in the image**
and **what the water does to the image**. Existing methods typically entangle these factors,
so changing water color or turbidity often alters object layout. WaterGen avoids this by
decoupling the two stages:

1. A LoRA-adapted SDXL backbone generates a **clean underwater scene latent** from a text prompt.
2. A **medium-conditioned decoder** applies physically meaningful attenuation and backscattering
   according to specified water parameters.

The same latent can be decoded under many water types without changing the underlying
geometry. This yields aligned clean/degraded pairs that can be used as synthetic training
data for underwater restoration and semantic segmentation.

## Quickstart

```bash
# 0. Environment (Python >= 3.10 + CUDA-capable PyTorch)
conda create -n watergen python=3.10 -y && conda activate watergen

# 1. Clone this repo
git clone https://github.com/jiayi-wu-umd/WaterGen.git
cd WaterGen
pip install -r requirements.txt

# 2. Download official weights
python scripts/download_weights.py

# 3. (Stage 1 only) Install Apple Depth Pro and point to its checkpoint
git clone https://github.com/apple/ml-depth-pro.git
export DEPTH_PRO_SRC="$(pwd)/ml-depth-pro/src"
export DEPTH_CHECKPOINT="/path/to/depth_pro.pt"

# 4. Generate a clean scene, then render water types
bash scripts/run_stage1.sh
bash scripts/run_stage2.sh
```

Stage 1 writes to `outputs/stage1/`. Stage 2 reads those latents/depth maps and writes
water-type variants to `variants_fixed/`.

Use a custom prompt with `PROMPT="an underwater scene of a shark swimming in the ocean near a rock" bash scripts/run_stage1.sh`.

## Weights

Downloaded by `scripts/download_weights.py` from [Hugging Face](https://huggingface.co/JiayiWuLeo/WaterGen):

- `stage1/pytorch_lora_weights.safetensors` — SDXL LoRA for clean underwater scene generation (rank 32, α 16).
- `stage2/model.pth` — medium-conditioned decoder that applies transmission and backscatter.

## Inference

`inference_stage1_clean_only_sdxl.py` generates a clean scene latent from text, optionally
runs a Stage 2 clean pass (`T=1, B=0`), and estimates depth with Depth Pro.

`inference_stage2_underwater_only_sdxl_fixed_waters_BL.py` decodes a saved latent under
UF7D-style water types (Deep Blue, Blue, Blue-Green, Green, Deep Green, …, Clear).

```bash
python inference_stage1_clean_only_sdxl.py \
  --prompt "an underwater scene of a shark swimming in the ocean near a rock" \
  --stage1_lora checkpoints/stage1 \
  --stage2_checkpoint checkpoints/stage2/model.pth \
  --lora_scale 0.9 \
  --output_dir outputs/stage1

python inference_stage2_underwater_only_sdxl_fixed_waters_BL.py \
  --input_dir outputs/stage1 \
  --stage2_checkpoint checkpoints/stage2/model.pth
```
